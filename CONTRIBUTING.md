# Contributing to Glimpse
Contributions to Glimpse are welcome, primarily through submitting issues.
Please open an issue to submit a bug report or feature request. Opening issues is the primary way to contribute to
Glimpse, and any bug reports or feature requests are greatly appreciated, regardless of how small or "out there" it may
be. If you have an idea or suggestion (even if small), please open an issue!

## TL;DR
- **Contributions involving a Generative LLM ("AI") will immediately be closed regardless of the submission**
- Open an issue to submit a bug report or feature request
- Small fixes and features are welcome, even without prior discussion
- Contributing themes or languages/locales is welcome and encouraged
- [Open an issue](https://github.com/aquagoose/Glimpse/issues/new/choose) or discuss it on the [Discord server](https://glimpseplayer.com/discord) **before** contributing larger fixes or features
- Plugin submissions should have a good reason to be bundled with Glimpse

### Usage of Generative LLMs ("AI")
LLMs are **NOT** to be used for **ANY** contributions. Glimpse is a project for humans, by humans.
Any contribution using an LLM in some way will be **immediately closed and denied**.
Glimpse follows [SDL's LLM policy](https://github.com/libsdl-org/SDL/blob/main/AGENTS.md). If you cannot contribute without using a generative model, we kindly ask that
you refrain from contributing.

### Contributing Themes/Languages
Theme and Language contributions are welcome and encouraged! If you'd like to add a new theme or language to be included
with Glimpse, you are welcome to open a pull request.

### Code Contributions
Code contributions adding minor fixes or features are welcome! If you'd like to add a small feature or fix a small bug,
you are welcome to open a pull request. However, if you'd like to contribute a larger change, please
[open an issue](https://github.com/aquagoose/Glimpse/issues/new/choose) or discuss it on the on the
[Discord server](https://glimpseplayer.com/discord) before contributing. **Larger contributions made without discussing it first will likely be denied.**

Contributions must be consistent with Glimpse's codebase and retain a similar coding style when possible.

### Submitting Plugins
If you wish to submit a plugin to be bundled with Glimpse, you should have a good reason why your plugin should be
bundled, instead of being a separate, downloadable plugin.

Good reasons include:
- Adding an audio codec
- A useful (but optional) feature that many users may enable

However plugin submissions have fairly loose requirements, so if you'd like to have your plugin bundled with Glimpse,
you are welcome to open an issue.
